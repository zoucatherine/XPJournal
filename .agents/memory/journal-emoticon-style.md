---
name: Journal emoticon style
description: Product direction for mood imagery in the retro journal.
---

Journal moods should use the supplied classic Messenger-style pixel emoticons rather than operating-system emoji artwork.

**Why:** The user requested more style-accurate emoticons to match the journal's retro desktop appearance; native emoji vary across devices and do not match that visual direction.

**How to apply:** Maintain this visual language when extending mood-related UI, without changing existing saved mood meanings just to change their appearance.
